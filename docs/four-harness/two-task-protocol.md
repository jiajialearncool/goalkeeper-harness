# 两道多阶段任务的四组对照

本轮使用同一已登录 ChatGPT 账户的订阅额度，不使用 OpenAI API Key，也不接入 Claude。模型统一为 gpt-6.1-sol，推理强度 xhigh。GoalKeeper 使用自身已有的订阅授权；Codex 使用原生登录；OpenCode、Pi 使用本地转发服务调用 GoalKeeper 已授权的订阅接口。转发服务只负责认证、订阅字段兼容、原始响应记录和用量检查，不提供 GoalKeeper 的规划、压缩、记忆或验证机制。

固定对照：GoalKeeper、Codex 0.159.0、OpenCode 1.18.34、Pi 0.73.1。使用官方安装包，Pi 不启用第三方扩展或自定义 Agent 循环；OpenCode 使用原生执行及会话。OpenCode 的普通模型和小模型均固定为同一模型。现有 Codex 原生 Goal 和子 Agent 设置保留。本轮不加入受控基线。

共八次计分尝试，每题每组一次。每次30分钟、100万可观测token，所有模型角色、摘要及修复共用预算。最多两次并行。资源中断保留同一尝试、消耗和工作文件，在剩余预算内最多续跑两次；任务失败不重跑、不择优。任何尚未解决的接入配置故障不能当作 Harness 的任务能力失败。准备、接入调用、等待和评分耗时另外报告。

## 第一题：改造订单退款和报表，并处理追加的优惠分摊规则（M1）

起始项目已有金额处理、参数校验、持久化和 CLI 接口，但优惠分摊、部分退款和客户净收入报表没有完成。交付实际文件及测试，保留原函数和命令行接口。

1. 完成订单报价：非负两位小数金额、正整数数量、唯一商品、优惠不能超过原价、优惠分摊总额精确守恒，保留旧版 total 接口。
2. 报价业务探针通过后追加规则：优惠按各行原价金额比例，以整数分和最大余数法分摊；余数相同按商品编号升序；零价行不分优惠；重排输入不得改变每个商品的优惠。
3. 完成部分退款和 SQLite 持久化：累积退款按优惠后净额计算，全部退完不能多退或少退；重复请求不重复退款；同请求编号不同内容报错；超退报错；错误不污染输入和已保存数据。
4. 完成客户净收入报表和 CLI：净收入=原价-优惠-已退款；重新打开数据库数据不丢失；成功输出 JSON，失败退出码2且不污染 stdout。补充测试和运行说明。

独立验收包含15项实例，覆盖金额、兼容入口、追加分摊规则、不同退款顺序、请求冲突、输入不变性、持久化和 CLI。执行 Agent 只能访问公共检查，不能读取独立评分程序。

## 第二题：迁移客户导入流程，中断后换会话完成审计和报表（M2）

起始项目包含 CSV、SQLite、幂等批次和审计接口，但以邮箱错误去重，空字段会覆盖旧字段，旧 JSON 迁移和报表未完成。

1. 修复 CSV 导入：客户以稳定 id 识别，不同 id 可以共用邮箱；空字段保留旧值；规范化邮箱和国家；任一无效记录使整批导入不写入；同 id 同内容只处理一次，不同内容整批报错。
2. 导入业务探针通过后停止执行进程，并启动新会话。各组收到相同目标和业务交接说明，可以核对自己工作目录中的实际文件。恢复前后的预算累计，不从零重新计时。
3. 完成旧版 JSON 迁移、持久化批次幂等和审计：同批次重排数据仍属重复，冲突拒绝；重复不新增审计；数据库重新打开后幂等信息仍在。
4. 完成国家汇总报表、客户 CSV 导出和 CLI：空国家计 UNKNOWN，缺邮箱单列数量；审计 before/after 正确；成功与失败输出契约同上。补充测试和说明。

独立验收包含11项实例，覆盖规范化、原对象不变、客户身份、空字段、原子导入、持久化审计、迁移、报表、导出和 CLI。必须出现真实关闭与新会话记录，不能只交付最终文件而省略恢复过程。

## 本轮可以回答什么

这是两个业务场景的中等规模多阶段比较。初始业务代码各128行，分别包含11和13个业务 Python 文件；另有公共测试文件。它们比最初的31–66行题目覆盖更多接口和阶段，但没有达到此前建议的800–1500行业务代码规模。因此本轮不能代表大型项目表现，也不能保证触发自然上下文压缩。实际压缩次数与目标变更/恢复事件均应报告。

两题独立评分结果为主指标。同时报告各组全部尝试的执行时间、可观测token、用量是否完整、交付状态及额外人工救援。每题一次运行只能提供初步信号，不进行稳定领先或普遍更优的统计宣称。

本轮结束后立即停止。即使四组都成功，也不自动提高难度或启动下一轮；先提供结果供用户决定下一步。

## 重新封存的准备修复

第一批计分运行在发现输入目录携带验收临时文件后整批作废。全部记录和已观察到的消耗保留，不能用于性能比较。新一批使用新运行编号与干净目录，复制时排除 .tmp、.home、.git 及缓存；独立评分文件只保存在执行进程无法读取的私有输入包中。

Codex 委派开始事件在未显式填写参数时，会出现空模型与 medium 推理档位占位值；不能把它当成实际配置。评测检查继续拒绝显式越界请求，并核对完成事件和会话的实际模型与推理档位。原生委派接入检查已观察到子 Agent 实际使用 gpt-6.1-sol / xhigh。
